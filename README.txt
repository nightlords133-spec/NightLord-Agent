Nightlord агент — сборка от 28.10.2026 (версия 2026.10.25)

СОСТАВ (раскладка по папкам)
  Установщик.bat        — окно установки (Python, пакеты, VPN, запуск, сборка exe)
  start_agent.bat       — запуск агента
  voice_agent.py        — сам агент
  plugins\              — плагины (рядом с voice_agent.py)
  setup\                — скрипты установки и сборки: install_gui.ps1, install_vpn.ps1, install_python.ps1/.bat,
                          check_deps.py (проверка пакетов), build_exe.py (сборка exe), nightlord.ico/.png
  Рядом с агентом при работе появятся settings.json, plugins.json, dialogs\ и т.п. — это ваши данные, не удаляйте.
  Команды вручную: py -3.12 setup\check_deps.py, py -3.12 setup\build_exe.py. Старая «плоская» раскладка
  (все файлы в одной папке) тоже работает.

НОВОЕ В ЯДРЕ
  Встроенный голос (работает без Voicebox): «Функции» → «Голос по умолчанию». Режим «Авто»: если Voicebox запущен —
  говорит он (клонированные голоса), иначе встроенный. Движки: Piper (офлайн; кнопки «Установить Piper» и «Скачать голос»,
  голоса Ирина/Дмитрий/Денис/Руслан, ~60 МБ каждый, с HuggingFace, один раз) и голоса Windows (SAPI, ничего ставить не нужно,
  нужен русский голос в системе). Есть скорость и кнопка «Проверить голос». Звук идёт тем же путём, что и у Voicebox:
  аватар, громкость, выбор колонок, Telegram и веб-чат работают как раньше.
  «Функции» → «Обновление» → «Обновить из файла…»: выберите новый .zip или voice_agent.py — агент проверит, сохранит
  старый как voice_agent.py.bak и предложит перезапуск (в exe не работает).
  Там же — обновление с GitHub: впишите «владелец/имя» репозитория, нажмите «Проверить обновления на GitHub».
  В репозитории в корне (или в любой папке) должен лежать voice_agent.py; для приватного репозитория нужен токен (только чтение).
  Резервная копия теперь включает настройки плагинов (ключи, токены) и спрайты аватара; есть копия без секретов.
  Кнопка «О программе» справа внизу (версия, автор). «Вывод звука» на вкладке «Агент» — выбор колонок/наушников.

КАК ОБНОВИТЬ
  1. Закройте агента. Замените voice_agent.py целиком.
  2. Файлы из папки plugins/ рядом с агентом удалите, если не правили их сами: агент поставит
     свежие встроенные версии. Свои правки он не перезаписывает — они остаются вашими.
  3. Плагины после замены файла выключаются: включите нужные заново на вкладке «Плагины».
  4. Настройки плагинов лежат в plugins/data/<имя>/ и при обновлении сохраняются.
  Плагины и ядро обновляйте вместе: новые плагины используют методы, добавленные в новый voice_agent.py.
