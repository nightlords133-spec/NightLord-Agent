Nightlord агент — сборка от 24.10.2026 (версия 2026.10.24)

СОСТАВ
  voice_agent.py   — сам агент (все плагины ниже уже встроены внутрь)
  build_exe.py     — сборка в exe:  python build_exe.py            (папка)
                                    python build_exe.py --onefile  (один файл)
                     Иконку берёт из nightlord.ico, если файл лежит рядом.
  check_deps.py    — проверка зависимостей
  Установщик.bat   — УСТАНОВЩИК С ОКНОМ (запускайте его): шаг 1 — Python 3.12, шаг 2 — пакеты (галочки), шаг 3 — ярлык и
                     запуск, шаг 4 — сборка в exe. Нужны рядом: install_gui.ps1, install_python.ps1, check_deps.py, build_exe.py.
                     Работает на встроенном PowerShell, Python для самого установщика не нужен.
  install_vpn.ps1  — модуль VPN для установщика (нужен рядом с install_gui.ps1): ссылка vless/vmess/trojan/ss, подписка или готовый HTTP-прокси;
                     ядро Xray скачивается с GitHub в папку vpn_core. Трафик pip и Python идёт через него. Ничего не сохраняется, при закрытии отключается.
  install_python.bat — установка Python 3.12 одним щелчком (winget или установщик с python.org с проверкой хэша и подписи),
                     затем предлагает поставить пакеты через check_deps.py
  start_agent.bat  — запуск агента: py -3.12 voice_agent.py
  nightlord.ico / nightlord.png — иконка
  plugins/         — те же плагины отдельными файлами (для справки или ручной замены)

НОВОЕ В ЯДРЕ
  «Функции» → «Обновление» → «Обновить из файла…»: выберите новый .zip или voice_agent.py — агент проверит, сохранит
  старый как voice_agent.py.bak и предложит перезапуск (в exe не работает).
  Там же — обновление с GitHub: впишите «владелец/имя» репозитория, нажмите «Проверить обновления на GitHub».
  В репозитории в корне (или в любой папке) должен лежать voice_agent.py; для приватного репозитория нужен токен (только чтение).
  Резервная копия теперь включает настройки плагинов (ключи, токены) и спрайты аватара; есть копия без секретов.
  Кнопка «О программе» справа внизу (версия, автор). «Вывод звука» на вкладке «Агент» — выбор колонок/наушников.

КАК ОБНОВИТЬ
  1. Закройте агента. Замените voice_agent.py целиком.
  2. Файлы из папки plugins/ рядом с агентом удалите, если не правили их сами: агент поставит
     свежие встроенные версии. Свои правки он не перезаписывает — они остаются вашими.
  3. Плагины после замены файла выключаются: включите нужные заново на вкладке «Плагины».
  4. Настройки плагинов лежат в plugins/data/<имя>/ и при обновлении сохраняются.
  Плагины и ядро обновляйте вместе: новые плагины используют методы, добавленные в новый voice_agent.py.

ЧТО НЕ ПРОВЕРЕНО НА РЕАЛЬНОЙ СИСТЕМЕ
  Инструменты: OCR Windows (winrt), реальные YouTube/VK через yt-dlp, UI Automation и клики по элементам, реальные Open-Meteo/ЦБ/CoinGecko — проверена логика на заглушках.
  Всё проверено на тестовых серверах и в Linux-песочнице. Не проверялись: окно на Windows 11 с темой sv_ttk,
  значок в панели задач, сборка exe, настоящие Telegram/Chrome-капчи/Home Assistant/облачные API.
